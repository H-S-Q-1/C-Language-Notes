# 学习任务管理器

一个使用 Python 标准库实现的命令行学习任务管理工具。

任务保存在项目目录下的 `tasks.json` 中，关闭程序后再次启动可以继续使用原来的数据。

## 当前版本

v1.1：排序与截止时间编辑

## 已完成功能

- 显示功能菜单。
- 每行输入一条任务，一次批量添加多条任务。
- 查看全部任务及完成状态。
- 使用空格或逗号输入多个编号，一次完成多条任务。
- 使用空格或逗号输入多个编号，一次删除多条任务。
- 批量操作时自动去重编号，并跳过无效编号。
- 已完成的任务不会重复完成。
- 批量删除时从后往前处理，避免编号移动导致误删。
- 按关键词搜索任务标题，不区分英文字母大小写。
- 按未完成或已完成状态筛选任务。
- 修改指定任务的名称，并保留原来的完成状态。
- 清空全部已完成任务，清空前需要输入 `y` 确认。
- 创建任务时自动记录创建时间。
- 查看任务总数、已完成数、未完成数和完成率。
- 兼容旧版任务文件，缺少创建时间的旧任务显示为“未知”。
- 为任务设置可选截止时间。
- 未完成且超过截止时间的任务显示“已逾期”。
- 任务统计中显示逾期任务数量。
- 按未完成、已完成或已逾期状态筛选任务。
- 将全部任务导出为 CSV 文件，方便使用表格软件查看。
- 按截止时间、创建时间或完成状态排序查看任务。
- 修改或清除指定任务的截止时间。
- 使用 `tasks.json` 保存任务。
- 程序重启后自动恢复任务。
- 处理无效菜单编号、非整数任务编号和越界编号。
- 处理 JSON 文件不存在、无法读取或格式错误的情况。

## 批量操作

### 批量添加

选择 `1` 后，每行输入一条任务，输入空行结束。

```text
> 学习 Python
> 刷一道算法题 | 2026-12-01 18:30
> 整理笔记 | 2026-11-25 21:00
```

竖线 `|` 后面的内容是截止时间，可以省略。

截止时间格式：

```text
YYYY-MM-DD HH:MM
```

### 批量完成与删除

选择 `3` 或 `4` 后，可以输入多个编号：

```text
1 3 4
```

也支持：

```text
1,3,4
```

程序会自动去除重复编号，并跳过非整数和越界编号。

## 搜索与筛选

- 搜索任务时按标题进行包含匹配。
- 英文字符搜索不区分大小写。
- 筛选功能可以显示未完成、已完成或已逾期任务。
- 搜索结果和筛选结果仍显示原任务编号，方便继续完成或删除。
- 修改任务时输入空内容可以取消。
- 清空已完成任务属于不可撤销操作，必须再次确认。
- 任务列表、搜索结果和筛选结果都会显示创建时间。
- 完成率保留一位小数。
- 截止时间格式错误时，本条任务不会添加，需要重新输入。
- 已完成任务不会显示为逾期。
- 排序只改变查看顺序，不修改任务编号，也不写入 JSON。
- 修改截止时间时输入 `clear` 或 `清除`，可以删除原来的截止时间。

## 数据文件

任务保存在：

```text
tasks.json
```

数据格式示例：

```json
[
  {
    "title": "学习 Python",
    "completed": false,
    "created_at": "2026-11-23 20:30:00",
    "due_at": "2026-12-01 18:30"
  },
  {
    "title": "刷一道算法题",
    "completed": true,
    "created_at": "2026-11-23 20:31:00",
    "due_at": ""
  }
]
```

`tasks.json` 已加入 `.gitignore`，不会提交到 Git。

## 导出记录

选择 `10` 后，程序会在项目目录生成：

```text
task_export.csv
```

CSV 中包含任务名称、状态、创建时间、截止时间和是否逾期。

导出的文件使用 UTF-8 编码，可以直接用 Excel 或 WPS 打开。

`task_export.csv` 已加入 `.gitignore`，不会提交到 Git。

## 运行方式

在项目目录中执行：

```text
python main.py
```
